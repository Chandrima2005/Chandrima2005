### ⚛️ InDEx n/γ Discrimination
**Telling a neutron's acoustic signature from a gamma-ray's.** Built with the Saha Institute of Nuclear Physics for a superheated-liquid dark-matter detector. The full pipeline runs on the real 200-event dataset: pulse localization, 512-D STFT features, and Logistic Regression and SVM trained from scratch. Drop in a raw waveform and it classifies it **right in your browser**.
