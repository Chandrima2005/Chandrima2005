I build **machine learning systems that you can actually open and use** — every project ships as a live, interactive web app, not just a notebook.

I'm currently pursuing a **Master's in Robotics & AI at IIT Guwahati**, after a B.Tech in Electronics & Communication Engineering. My work sits where **electronics, physics and ML** meet:

- ⚛️ **Scientific ML** — acoustic signal classification for superheated-liquid dark-matter detectors, in collaboration with SINP
- 📚 **Grounded AI** — retrieval-augmented systems that answer from *your* documents, not the open internet
- 👁️ **Computer vision** — stereo depth estimation from image pairs and camera metadata
- 🧭 **Learning tools** — interactive atlases that make classical ML explorable

Every system I build is:

- 🔬 **Evidence-first** — results verified on real data, with confusion matrices and held-out test sets
- 🖥️ **Runs in the browser** — inference happens client-side where possible; nothing gets uploaded
- 📎 **Grounded** — answers and predictions are traceable back to the source signal or passage
- 🎨 **Designed** — a clear interface is part of the engineering, not an afterthought

### ⚛️ [InDEx n/γ Discrimination](https://neutron-gamma-detector.chandrima-das.com/)

![Live](https://img.shields.io/badge/Live_Demo-Online-c9d1d9?style=flat-square&labelColor=0d1117)
![Physics](https://img.shields.io/badge/Dark_Matter-Research-6e7681?style=flat-square&labelColor=0d1117)
![SINP](https://img.shields.io/badge/SINP-Collaboration-6e7681?style=flat-square&labelColor=0d1117)

Separates **neutron** from **gamma-ray** events in a C₂H₂F₄ superheated liquid detector using only the acoustic pulse of each bubble nucleation. Full pipeline on a 200-event dataset: pulse localization → **512-D STFT features** → Logistic Regression & Linear SVM trained from scratch (30k SGD epochs). Drop in a raw `.lvm` waveform and it classifies **entirely in your browser**.

**Stack:** Python · NumPy · STFT · SGD · JavaScript

### 👁️ [StereoVision Pro — Depth Estimation](https://github.com/Chandrima2005/depth-estimation-using-stereo-images)

![Repo](https://img.shields.io/badge/Source-GitHub-c9d1d9?style=flat-square&labelColor=0d1117)

## 🏛️ How I Build

```
┌─────────────────────────────────────────────────────────────────────┐
│                  FROM RAW SIGNAL TO LIVE PREDICTION                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐               │
│  │    Signal    │  │   Features   │  │    Model     │               │
│  │  ──────────  │  │  ──────────  │  │  ──────────  │               │
│  │ waveforms /  │→ │ STFT / SGBM  │→ │ LR · SVM ·   │→  Browser UI  │
│  │ stereo pairs │  │ disparity /  │  │ RAG + LLM    │               │
│  │ / PDFs       │  │ embeddings   │  │              │               │
│  └──────────────┘  └──────────────┘  └──────────────┘               │
│                                                                     │
│  Design Principles:                                                 │
│  ✦ Real data first — validate on held-out sets, not toy examples    │
│  ✦ Understand the physics — features come from the signal itself    │
│  ✦ Grounded outputs — every answer traceable to its source          │
│  ✦ Client-side where possible — no uploads, instant feedback        │
│  ✦ Ship it live — a demo link beats a screenshot                    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
